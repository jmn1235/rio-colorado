Puesta en marcha en Firebase y GitHub

Lo que falta hacer una sola vez para que la app quede operativa en la nube

  1. Entrá a console.firebase.google.com y creá un proyecto llamado rio-colorado. Es gratis en el plan Spark.
  2. En Compilación → Authentication, activá el proveedor Google.
  3. En Compilación → Firestore Database, creá la base en modo producción, región southamerica-east1.
  4. En Configuración del proyecto → Tus apps, agregá una app web y copiá el objeto firebaseConfig.
  5. Abrí este archivo HTML con el Bloc de notas, buscá CONFIG_FIREBASE arriba de todo y pegá ahí los valores. Guardá.
  6. En Firestore → Reglas, pegá las reglas que están en el archivo INSTRUCCIONES.md que viene junto a esta app. Solo dejan entrar a los dos correos autorizados.
  7. Creá un repositorio en GitHub, subí el HTML con el nombre index.html y activá Settings → Pages desde la rama principal.
  8. En Firebase → Authentication → Configuración → Dominios autorizados, agregá el dominio que te dio GitHub Pages.
